# Mary and Matt

Wedding website for Mary and Matt.

Created with HTML, CSS, and vanilla JavaScript. Built using Parcel and deployed with Github Pages.

## Local Development Instructions

1. Run ```npm install``` to generate node_modules.
2. Run ```npm run start``` to start the local development server.
3. Navigate to [http://localhost:1234](http://localhost:1234) to view the local changes.

## Build and Deploy Instructions

1. Run ```npm run build``` to generate the dist folder.
2. Create a CNAME file with the custom domain name www.maryandmattwedding.com in the dist folder, if it hasn't been added already.
3. Run ```npm run deploy``` to deploy the changes to GitHub pages.
